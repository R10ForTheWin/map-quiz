# Oreo's Map Quest

Interactive geography practice for elementary students: US states and capitals, state abbreviations, world countries and capitals, ISO country codes, and continents and oceans.

**[Play it →](https://r10forthewin.github.io/map-quiz/)** (best on a laptop or desktop)

Drag each name onto the map, with a choice of instant right/wrong feedback or a score at the end. Built for two specific kids who were never going to sit still for flashcards.

Plain HTML and JavaScript, with D3 and TopoJSON for the maps. Installable as a web app and works offline.
